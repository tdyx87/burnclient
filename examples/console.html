  1. 放入一张空白 CD-R（DVD 则是 DVD-R）。
    2. 
      
  2. 在上面第一步里选中你的刻录机。
    3. 
      
  3. 第二步选「把文件刻成光盘」。
    4. 
      
  4. 第三步填入 .iso 文件路径，或者一个文件夹路径。
    5. 
      
  5. 点开始刻录，然后等进度条走完。
    6. 
    


    
各选项是什么意思

    
    
      
  • 光盘类型：按手上空白盘的种类选。填错会导致刻录失败。
    • 
      
  • 刻完后检查：把光盘内容读回来比对。抽查快、逐扇区慢但最可靠。
    • 
      
  • 刻完后不封盘：留出以后追加内容的空间。日常使用不用勾。
    • 
      
  • 可启动的光盘：填入系统启动文件，刻出的盘可以开机引导。
    • 
    


    
音乐 CD 的要求

    
必须是 44.1 kHz / 16 位 / 立体声 的 WAV，且每首至少 4 秒。不满足时程序会在刻录前就报错，不会浪费光盘。


    
常见问题

    
    
      
  • 设备列表是空的：这台电脑没有能刻盘的驱动器。虚拟机里的虚拟光驱通常不能刻盘。
    • 
      
  • 提示「无法独占打开」：驱动器被其他刻录软件占用了，关掉那些程序再试。
    • 
      
  • 提示 UDF 不支持：当前后端无法生成 UDF 格式，换用普通 ISO 格式即可。
    • 
      
  • 刻录中途失败：介质质量差或驱动器过热，换一张新盘、或把速度调低再试。
