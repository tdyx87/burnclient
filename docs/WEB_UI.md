# Web 控制台使用说明

`burn_webui` 是一个**本地网页控制台**，把刻录库的六类能力变成图形界面：
选设备、选功能、填路径、看进度、随时取消。它不需要任何 GUI 工具链，
Windows / Linux / macOS 上行为一致。

```
burn_webui                       # 默认 127.0.0.1:8712，并自动打开浏览器
burn_webui --port 9000           # 换端口
burn_webui --no-browser          # 不自动开浏览器
burn_webui --exit-after 600      # 10 分钟后自动退出
```

打开后浏览器会进入控制台。

> **安全**：服务只绑定 `127.0.0.1`，局域网内其他机器访问不到。
> 但它能刻盘、擦盘，**不要**把它暴露到公网，也不要在不可信的系统上启动。

---

## 界面分区

| 页签 | 能做什么 | 对应后端能力 |
|---|---|---|
| **数据盘** | 刻录已有 `.iso` 或把目录打包刻录；可选「保留会话可追加」；可选刻后回读校验 | `image_burn`、`readback_verify`、`multisession` |
| **音频 CD** | 按行填入 WAV 生成 CD-DA 音轨，可选择是否写入目录表并封盘 | `audio_tao` |
| **镜像制作** | 从目录生成 ISO：卷标、ISO 级别、ISO9660/Joliet/UDF、El Torito 引导镜像 | `create_image`、`udf`、`boot_image` |
| **RAW** | 用 WAV 生成 RAW 镜像（可填 MCN 与起始轨号），或把 RAW 镜像写入光盘 | `raw_image`、`raw_burn` |
| **维护 / 多会话** | 擦除（快速/全擦）、弹出与收回托盘、查询下一会话起始块、追加会话 | `erase`、`tray_control`、`multisession` |

右上角的设备下拉框列出所有刻录机；左侧面板实时显示当前后端支持哪些能力
（不支持的会标成灰色 ✗），并可展开设备详情（厂商、型号、介质状态、可写性）。

## 使用要点

### 1. 选设备

下拉框列出系统报告的刻录设备。名称带 `[只读/不可写]` 的说明该设备当前
无法独占打开（被占用、驱动写保护或不是真正的刻录机），刻录类操作会失败。

### 2. 刻录数据盘

1. 「数据盘」页填入 `.iso` 路径（或源目录）
2. 选介质类型、速度（`0` = 驱动器默认）
3. 校验等级：
   - **不校验**：只刻录
   - **快速校验**：刻录后抽样比对
   - **完整校验**：刻录后逐扇区比对，最慢
4. 点「开始刻录」，下方进度条显示百分比，任务阶段显示当前在做什么
5. 需要中断时点「取消当前任务」

### 3. 音频 CD

在文本框里**每行一个** WAV 路径。要求：

- 44.1 kHz / 16 bit / 立体声 PCM
- 每轨至少 4 秒

格式不符会在**刻录前**被拒绝并说明原因，不会白白浪费一张盘。

### 4. 镜像制作

填源目录与输出路径即可。可选：

- **文件系统**：含 UDF 的选项在不支持 UDF 的后端（如 Linux/libisofs）
  会自动置灰并标注
- **ISO 级别**：1/2/3，留默认则用后端默认
- **El Torito 引导镜像**：填引导镜像文件路径，生成的 ISO 就能引导启动

### 5. RAW

填入 WAV 与输出路径生成 RAW 镜像，再点「把 RAW 镜像写入光盘」。

> **Windows 与 Linux 生成的 RAW 镜像格式不同，不能跨平台互换烧录。**
> 请在同一平台内成对使用。

### 6. 多会话

1. 先用「数据盘」页勾选**保留会话可追加**刻一张盘（不封盘）
2. 到「维护 / 多会话」页点「查询」确认下一会话起始块
3. 填入要追加的内容目录，点「追加会话」

追加后最后一个会话的内容可见，部分系统下也能读到之前的会话。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 设备列表为空 | 系统未报告刻录机。虚拟机里的虚拟光驱通常**不能**刻录 |
| 设备显示 `[只读/不可写]` | 驱动写保护、设备被其他刻录软件占用，或该虚拟光驱不支持 IMAPI2 刻录 |
| 刻录立刻失败并提示 E_ACCESSDENIED | 同上：该设备无法独占打开 |
| 音频被拒绝 | 不是 44.1k/16bit/立体声，或短于 4 秒 |
| UDF 选项是灰的 | 当前后端不支持 UDF（Linux 的 libisofs 没有 UDF 写入器） |
| 生成镜像报「Cannot open output file」 | 输出路径不可写或目录不存在 |
| 进度条卡在某个百分比不动 | 点「取消当前任务」；再检查驱动器状态 |

## 自动化测试

控制台本身在 CI 里被完整跑过：`tests/test_webui.cpp` 会真实启动服务、
用 HTTP 调用每个接口、跑完一个无盘任务并检查错误路径。

```
ctest -R webui_console
```
